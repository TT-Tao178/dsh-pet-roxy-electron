# roxy-desktop-pet 🐰

**洛琪希（Roxy）桌面宠物** —— 一个透明的、总在最前的悬浮窗小宠物，跑在 Windows 桌面上，**不再依赖 DSH**。

这是从 [dsh-pet-roxy](https://github.com/)（DSH 插件版）迁移出来的独立 Electron 版：**去除了余额 / 今日已用 / 每轮消耗等计费功能**，保留了宠物本体：表情与行为、任务看板与统计、右键配置（自定义台词 / 上传表情图 / 行为设置）、无口傲娇台词。

- 不需要 API Key，不需要 DSH，不需要联网
- 拖住她就能在屏幕上移动位置（位置会自动记住）
- 右键菜单里有「退出」，双击她她会犯困

## 运行（一键）

**最简单：双击 `start.bat`** —— 首次会自动安装依赖（下载 Electron 约 100MB，需网络），之后每次双击就直接启动。退出宠物：右键 Roxy → 菜单 → 退出，或右下角托盘图标右键 → 退出。

**想开机自启**：装好后在 设置 → 行为 里勾选「开机自启」即可（或双击旧脚本 `add-autostart.bat`；取消用 `remove-autostart.bat`）。

**命令行方式**（可选）：

```powershell
cd dsh-pet-roxy-electron
npm install
npm start
```

## 她能干什么

| 操作 | 效果 |
|---|---|
| 单击她 | 行为一 / 行为二随机切换 + 一句台词 |
| 双击她 | 行为四（犯困） |
| 拖住她 | 在屏幕上移动（松手位置自动记住） |
| 右键她 | 菜单：说话 / 数据统计 / 添加任务 / 设置 / 退出 |

- 会呼吸；任务进行中会切到「行为三」工作态（80%），平时 20% 概率出现；25~35 秒随机犯困（行为四，任务进行中不犯困）
- 任务看板：右键 → 添加任务（黄色便签），数据统计里看今日任务 / 已完成 / 进行中 / 失败 + 环形图 + 7 天趋势
- 右键 → 设置：自定义台词、上传表情图（PNG/JPG/WebP ≤2MB）、调整大小 / 镜像 / 动画 / 犯困频率
- 设置 → 行为：**置顶方式**（一直置顶 / 仅桌面置顶）、**开机自启**、**透明度滑条**、**鼠标穿透**（点击透过她操作下层；开启后从**托盘图标**取消勾选即可关闭）

## 行为与图片对应

| 行为 | 图片 | 什么时候出现 |
|---|---|---|
| 默认 | `assets/roxy0.png` | 启动 / 待机 |
| 行为一 | `assets/roxy1.png` | 单击她（与行为二随机二选一）；任务完成 |
| 行为二 | `assets/roxy2.png` | 单击她（与行为一随机二选一）；任务失败 |
| 行为三 | `assets/roxy3.png` | 任务进行中 80% 概率，平时 20% 概率（工作态） |
| 行为四 | `assets/roxy4.png` | 双击她；随机犯困（25~35 秒、30%） |

图片可在「设置 → 图片」上传替换；每个槽位有「预览」按钮。

## 数据存哪

全部在本地，与 DSH 无关：

| 位置 | 内容 |
|---|---|
| `%USERPROFILE%\.roxy-desktop-pet\config.json` | 你的设置（大小 / 镜像 / 台词 / 表情覆盖） |
| `%USERPROFILE%\.roxy-desktop-pet\tasks.json` | 任务清单 |
| `%USERPROFILE%\.roxy-desktop-pet\uploads\` | 你上传的表情图 |
| `%USERPROFILE%\.roxy-desktop-pet\window.json` | 窗口位置记忆 |

> 可用环境变量 `ROXY_HOME` 改到别处。

## 与 DSH 插件版的关系

- 本目录是**独立副本**，原项目 `dsh-pet-roxy`（DSH 插件版）未做任何改动；
- 迁移删掉的功能：余额拉取、记账、每轮对话消耗、峰谷定价、DSH 凭据/会话事件；
- 迁移保留并微调：表情/行为、任务看板、统计、右键配置、无口傲娇台词；

- 代码：MIT
- 素材（`assets/` 下的图片）：仅限个人使用，禁止商用
